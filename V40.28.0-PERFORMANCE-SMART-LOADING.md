# Math12 Hub v40.28.0 — Performance & Smart Loading

- Hall of Fame public documents now include a compact `rankSignal`; realtime view listens to the 300 most recently active public profiles instead of every public profile. A `rankSignal` is also written for future server-side ranking work.
- PWA install cache is slimmer: heavy avatar source images and already-lazy AI/Reports modules are no longer blocking shell installation.
- MathJax stays in the offline shell because mathematical rendering is a core requirement.
- Images outside active exam/avatar rendering are lazily decoded.
- Lightweight runtime performance diagnostics track page switch cost, resources and long tasks.
- `?safe=1` disables the new performance hooks.
