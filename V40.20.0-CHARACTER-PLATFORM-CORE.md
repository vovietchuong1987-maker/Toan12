# Math12 Hub v40.20.0 — Character Platform Core

## Mục tiêu
Chuyển hệ Avatar từ nhiều module gọi chéo nhau sang một API công khai duy nhất: `M12CharacterPlatform`.

## Kiến trúc mới
- `M12CharacterPlatform`: nguồn truy cập chuẩn cho identity, appearance, economy, wardrobe/shop, achievements và presence.
- `Character Runtime`: event bus + điều hướng + account hydration; không còn renderer registry cũ.
- `M12CharacterAssetRenderer`: Asset/Mask Renderer duy nhất cho giao diện nhân vật.
- `AvatarEngine`, `v379Economy`, `v385Wardrobe`, `v386MegaShop`, `v388Achievements` vẫn được giữ làm adapter dữ liệu bên dưới để không đổi schema Firestore.

## Thay đổi chính
1. Bỏ `avatar-renderer-2d-v40.18.3.js` khỏi production.
2. Bỏ `avatar-runtime-v40.19.7.js`, thay bằng `character-runtime-v40.20.0.js`.
3. Avatar/Shop/Dashboard ưu tiên đọc và ghi qua `M12CharacterPlatform`.
4. Có API presence dùng chung cho Hồ sơ/Đấu trường sau này: `mountPresence()` và `[data-character-presence]`.
5. QA mới kiểm tra Character Platform + Asset/Mask Renderer thay vì renderer SVG cũ.
6. Không tạo collection/document Firestore mới; dữ liệu cũ giữ nguyên.
7. Room vẫn tắt; `roomV390` cũ không bị xóa.
