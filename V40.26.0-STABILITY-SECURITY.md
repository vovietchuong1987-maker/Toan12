# Math12 Hub v40.26.0 — Stability & Security Core

- Added a Firebase runtime bridge for add-on modules (Arena can reliably see the authenticated user/database).
- Arena accepts scores only from a recent `math12hub:attempt-rewarded` event emitted by the main exam engine.
- Arena score/duration/progress are validated locally before Firestore write.
- Added hardened Firestore Arena rules for owner-only room transitions and self-only player writes.
- App Check remains optional until a valid site key is configured; enforcement should be enabled only after metrics are healthy.
- No question/exam schema migration.
