Math12 Hub V37.5.1 — Dynamic Practice Engine

Scope
- Base: V37.5 Figure Production Engine.
- New: lesson/chapter practice generated from question bank.
- Package-clean policy: current runtime only; no historical root SW/README/VALIDATION/preview/test/import files.

Functional rules
1. Lesson practice: max 8 eligible questions from exact lesson scope.
2. Chapter review: 12–20 questions depending on chapter/pool size.
3. If reviewStatus exists in the scope, only Approved questions are student-eligible.
4. Figure QC fatal failures are excluded when Figure QC API is available.
5. Selection priority: lesson coverage (chapter mode) -> ID6/form coverage -> knowledge coverage -> level balance -> random fill.
6. “Current set” persists question IDs in localStorage to support resume.
7. “New set” clears old draft for that scope and penalizes questions from the previous set to reduce repetition.
8. No question content, answer, ID6, reviewStatus or Firestore schema is modified.

Validation commands are recorded during build: JS syntax, referenced local files, service-worker core files, ZIP integrity, clean-root policy.
