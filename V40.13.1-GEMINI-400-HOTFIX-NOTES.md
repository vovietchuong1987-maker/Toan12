# Math12 Hub V40.13.1 — Gemini 400 INVALID_ARGUMENT Hotfix

Build: `40.13.1-gemini-invalid-argument-hotfix`

Nâng trực tiếp từ V40.13, không thay Question Bank, ID6, avatar, navigation hoặc Firestore.

## Sửa lỗi chính

- Sửa lỗi Gemini `400: Request contains an invalid argument` ở AI Import Pipeline.
- `generateContent` ưu tiên cấu hình tương thích `responseMimeType: application/json` + `responseSchema`.
- Nếu Gemini từ chối schema/ThinkingConfig bằng `INVALID_ARGUMENT`, hệ thống tự retry theo chuỗi tương thích:
  1. JSON + schema + thinking;
  2. JSON + schema, bỏ thinking;
  3. JSON MIME, bỏ schema;
  4. JSON MIME, bỏ schema và thinking;
  5. JSON theo prompt, không cấu hình structured output.
- Lỗi 400 dạng chung cũng kích hoạt fallback; không còn phụ thuộc Gemini phải trả chữ `responseFormat` trong thông báo lỗi.
- Chuẩn hóa media request về `inlineData.mimeType` trước khi gửi REST API (ảnh/PDF và ảnh nhúng từ DOCX).
- Checkpoint V40.13 được giữ nguyên; không xóa hàng chờ AI hoặc tiến trình đang lưu.
- Đổi cache-busting và Service Worker sang V40.13.1 để GitHub Pages không giữ JS cũ.

## Lưu ý

Nếu cả 5 request modes đều bị Gemini từ chối, giao diện sẽ báo rõ hệ thống đã thử fallback. Khi đó cần kiểm tra model/API key hoặc chính tệp đầu vào, thay vì chỉ hiện thông báo 400 chung.
