# Math12 Hub v40.30.0 — Production Quality Gate

## Runtime guard
- Checks critical APIs, role map, duplicate DOM IDs, Local Storage, Security Core, Delta Sync, Performance, UX, Arena and Service Worker support.
- Keeps the last 20 runtime errors locally; nothing is uploaded by this module.
- Records a `last known good` marker after all critical checks pass.
- Admin page gets a compact system-health card and diagnostics export.

## Safe Mode
Open the site with `?safe=1` to temporarily bypass the v40.27 Delta Sync, v40.28 Performance hooks and v40.29 UX layer. The v40.26 security bridge stays active. This is intended for troubleshooting/rollback without deleting data.

## Deployment
Use `tools/verify_release.py` before upload. Keep the previous GitHub Pages release available until v40.30 has been smoke-tested with Student, Teacher and Admin accounts.
