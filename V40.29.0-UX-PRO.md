# Math12 Hub v40.29.0 — UX Pro

- Added keyboard-accessible skip link and visible focus states.
- Modals now expose dialog semantics, trap focus, support Escape, and restore focus when closed.
- Navigation updates `aria-current` and browser title based on the current page.
- Common technical English labels visible to students are translated to concise Vietnamese.
- Offline status is shown as a small non-blocking badge.
- Mobile form controls use touch-friendly sizes and avoid iOS input zoom.
- `prefers-reduced-motion` and low-data/low-memory modes reduce animation automatically.
- `?safe=1` bypasses the UX enhancement layer for troubleshooting.
