# Math12 Hub v40.27.0 — Firestore Delta Sync

## What changed
- First sync on a device performs one compatibility bootstrap using the existing full-collection mechanism.
- Later teacher-content syncs compare compact per-document hashes stored locally and write/delete only changed documents.
- Repeated saves no longer read the entire `questionBank`, `customExams`, and recycle-bin collections before every write.
- Existing v21 cloud conflict detection remains authoritative on login; no collection path was renamed.
- Add `?safe=1` to the URL to bypass Delta Sync and temporarily use the legacy sync path for troubleshooting.

## Expected impact
For a 2,000-question bank where one question changes, normal post-bootstrap sync is approximately one document write instead of a full collection read plus rewrite.
